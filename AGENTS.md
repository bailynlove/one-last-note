# one-last-note

Specification workspace for a collaborative note-management product (Notes, Knowledge Bases, Comments, Marks, Chrome Saver, App Extensions, MCP control). Glossary: `CONTEXT.md`.

## Agent skills

### Issue tracker

Issues live as GitHub issues in `bailynlove/one-last-note` via the `gh` CLI, map issue #1. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary, each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.
